Demander la suppression du compte

S'applique à : Agenzo – Smart Reminders (Android)

Option A — Supprimer dans l'application (le plus rapide)

Si vous avez encore accès à l'application :

  • Ouvrez Agenzo → Paramètres → Compte → Supprimer le compte
  • Cela supprime votre compte et les données associées stockées dans notre backend Firebase.

Option B — Demander la suppression via le web (sans application)

Si vous ne pouvez plus accéder à l'application, vous pouvez demander la suppression ici :

🧾 Ouvrir le formulaire de demande de suppression

Étape de vérification importante : Pour éviter les abus, nous traiterons la suppression uniquement après avoir confirmé que vous contrôlez l'e-mail du compte. Nous pouvons vous envoyer un e-mail pour confirmer votre demande.

Ce que nous supprimons

  • Votre compte Agenzo (utilisateur Firebase Authentication)
  • Vos rappels, tâches et rappels de localisation stockés dans notre base de données

Contact
