Kontolöschung beantragen

Gilt für: Agenzo – Smart Reminders (Android)

Option A — In der App löschen (am schnellsten)

Wenn Sie noch Zugriff auf die App haben:

  • Öffnen Sie Agenzo → Einstellungen → Konto → Konto löschen
  • Dadurch werden Ihr Konto und die zugehörigen Daten in unserem Firebase-Backend gelöscht.

Option B — Löschung über das Web beantragen (ohne App)

Wenn Sie keinen Zugriff mehr auf die App haben, können Sie die Löschung hier beantragen:

🧾 Formular zur Löschanfrage öffnen

Wichtiger Verifizierungsschritt: Um Missbrauch zu verhindern, bearbeiten wir die Löschung erst, nachdem wir bestätigt haben, dass Sie die Konto-E-Mail kontrollieren. Wir können Ihnen eine E-Mail senden, damit Sie Ihre Anfrage bestätigen.

Was wir löschen

  • Ihr Agenzo-Konto (Firebase Authentication Nutzer)
  • Ihre Erinnerungen, Aufgaben und standortbasierten Erinnerungen in unserer Datenbank
